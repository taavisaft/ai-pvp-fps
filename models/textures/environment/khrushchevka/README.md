# Khrushchevka candidate concrete material

Downloaded 2026-10-09 from https://ambientcg.com/view?id=Concrete034.

Creator: ambientCG / Lennart Demes.
License: Creative Commons CC0 1.0 Universal.
License information: https://docs.ambientcg.com/license/

Unmodified 1K JPG maps: Color, NormalGL and Roughness. The Khrushchevka exterior
loads the Color map; normal and roughness remain source assets. The shader adds
subtle near-field grain and streaks. This is smooth concrete, not a scan of the
reference building's pebble-dash surface.

Original archive and building research: `docs/references/khrushchevka/` and `docs/khrushchevka-research-2026-10-09.md`.
