AI PvP FPS — macOS Apple Silicon v0.1.1

Extract this ZIP and drag AI PvP FPS.app to Applications, then open it.
Requires an Apple Silicon Mac. Built for macOS 12+, tested locally on macOS 27.
Intel Macs are not supported by this package.

This build is ad-hoc signed, not Developer ID signed or notarized. macOS may
block an internet download. If you trust the download, use the app-specific
Open Anyway option in System Settings > Privacy & Security after trying to
open it. Do not disable Gatekeeper globally.

Starts in the offline training lobby. WASD move, mouse aim, left click fire,
right click aim down sights, R reload, Space jump, Shift sprint, Esc quit.
Press C to connect to a running server by address. No public server is included.
See CONTROLS.md for the full control list.

The optional ground.jpg texture is omitted pending verification of its
redistribution rights; the game uses its existing material fallback.
